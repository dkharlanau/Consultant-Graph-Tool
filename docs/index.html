    02 / Architectural decisions

    Where software ends and judgment starts.

    01

    Deterministic by default

    The graph evaluates synthetic SAP determination keys with regular Python. A probabilistic model must not invent master data or configuration.

    02

    Evidence before action

    The graph verifies fixture evidence-reference coverage. Missing references suppress recommendations; passing this check does not validate facts in any live SAP system.

    03

    Bounded autonomy

    Retries stop after three attempts. Human review uses a checkpoint and an explicit resume decision; it never changes SAP.

    04

    Portable scenario packs

    LangGraph orchestration is shared. SAP Logistics is an adapter; a future pack can diagnose MDG, integration or migration issues.

    Important boundary: This example represents a simplified classic sales-order determination path. SAP behavior depends on release, customizing and document context. The UI replays actual offline graph results, not a live SAP or LLM integration.
    03 / Reproduce it locally

    From browser replay to executable graph.

    python -m pip install -e ".[dev]"
cgt list
cgt run no-route-rule
cgt run no-route-rule --review --decision approve
cgt export-traces --output docs/traces.json
python -m http.server 8000 --directory docs

    See the README and architecture decision record for boundaries, extension instructions and tests. For domain detail, read SAP Route Determination and LangGraph human interrupts.
