# Consultant Graph Tool

A small, open-source graph execution lab for consultants. Start with a reproducible SAP S/4HANA sales-order logistics diagnostic workflow and extend it to other domains.

The first release is built around **LangGraph**, deterministic rules, synthetic data, evidence-linked findings, and an optional human review gate. No SAP connection or LLM key is required.

Implementation is developed in a feature branch. See the upcoming pull request for executable code, tests, and an interactive trace viewer.

**Safety:** educational example; no production data, credentials, or SAP write operations.
